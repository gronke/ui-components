# ADR 0021: The class map becomes a stylesheet

## Decision

The crate `uic_css` parses real CSS with servo's cssparser and selectors crates into a closed, terminal-meaningful property set; every other declaration drops silently and is counted — the degradation contract of ADR 0026, made measurable.
Unknown pseudo-classes parse and never match (`:hover` on a terminal), so a rule keeps its other selectors alive; `:focus` matches the runtime's focused node.

Layout and paint read computed styles cascaded from stacked origins — `ua.css`, the generated `bootstrap-tui.gen.css`, per-component sheets, and the overrides sheet — with `!important`, specificity and source order inside each origin.
Origin dominates importance, deviating from full CSS's author rules: the overrides sheet must reliably beat generated Bootstrap, `!important` included, or the curated overlay cannot be trusted.
Component sheets scope to their instance's subtree with `:host` as the component element, while the outer origins deliberately reach inside — the terminal DOM is light DOM throughout.
A component's `static styles` enter through the host (`uic_tui::dom::adopt_component_sheet`, called by the mocked lit's `customElements.define`): custom properties, `var()`, `calc()` and scoped element rules drive colors and indentation, and an element whose background differs from its parent's fills its box — a `:host` background paints the whole component area.

Cells are the unit: one column is 0.75rem/12px/1ch, one row is 1.5rem/24px/1lh — Bootstrap's own body line-height.
Lengths round half away from zero and may round to nothing (`mt-1` stays invisible); borders and gaps floor at one cell, because a separator that vanishes fuses what it separates.
The dialect's color space carries the ANSI palette (`ansi(light-red)`) beside 24-bit values, and the CSS system color `Highlight` as a background reads as reverse video — so the sheets can hit the exact `ratatui` variants the tests probe.

`bootstrap-tui.gen.css` is generated by filtering the real compiled Bootstrap (`gen-tui-css`): rules survive when their selector parses, their subject compound carries a class, id or attribute (or is `:root`, the custom-property carrier), and their declarations name supported properties.
The element reboot stays out — bare-element defaults are `ua.css` territory — and values keep Bootstrap's own units, converted by the engine.
`tui-overrides.css` carries the terminal-specific residue explicitly: ANSI text colors, the bold label, the bordered blocks' cell reservations, seamless chrome removal (`[seamless] .input-group`), and form controls hugging content instead of Bootstrap's `width: 100%`.
The generated sheet is committed; regenerating on a Bootstrap bump is a reviewable diff.

The engine is pinned by byte-identical frames: the entire TestBackend suite passes with it active.

The inline stage builds the boxes CSS generates beyond the document tree.
Rules targeting `::before`/`::after` resolve in a pseudo pass per element (inheriting from the owner, gated by a sheet-level fast-path flag), and a cascade that produced `content` synthesizes a generated box: sized by the pseudo style, hit-testing to its owner, its marker glyph swapped by right-angle `transform: rotate(...)` at synthesis — json-viewer's ▶ turning ▼.
Block containers wrap runs of two or more consecutive inline-level boxes (text, `display: inline`/`inline-flex` elements, generated content) into anonymous wrapping flex rows; inline whitespace processing collapses interiors, trims run edges like line ends, and keeps one separator cell where the markup had one.
Flex and grid containers blockify their children — which is what keeps the catalog goldens byte-identical through this stage.
An inline element is itself a wrapping row: each inline box breaks lines on its own, the stage's approximation of one shared inline formatting context.
The ua sheet marks the prose tags (`span, a, b, i, em, strong, small, code, mark`) inline.

## Why

Committed attributes are the runtime's stylesheet selectors (ADR 0008); a real stylesheet makes the rest of styling data too.
Styling facts kept in runtime code turn every gap — list indentation, a foreign component's palette, a spacing utility — into a runtime edit, and foreign components' `static styles` need a place to go.

## Consequences

- Styling gaps close with sheet edits, not runtime edits; the dropped-declaration counts are the future lint's input (ADR 0026's reserved slot).
- Generated content carries text only (`content`, sized by the pseudo style); counters, images and `attr()` stay out of the dialect.
- What stays in code: the focus/error ring colors on bordered blocks, the mounted-root flow margin, and widget intrinsic sizing — runtime behavior, not stylesheet fact.
- Inheritance is per-property (color, text styling, custom properties); background inherits as the terminal's stand-in for transparency — a documented approximation.
- `uic_tui` carries the sheets and resolves them per layout pass; a per-commit style cache is the recorded performance knob.
- The `selectors` Element view over `uic_dom` also serves selector queries: the JS host's `matches`/`querySelector` natives run on the same engine the cascade uses, `:focus` fed from the host's focus.
